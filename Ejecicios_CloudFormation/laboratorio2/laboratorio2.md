# 🧪 **Laboratorio:**

## 🎯 **Objetivo del laboratorio**

- Crear un s3 usando Cloud Formation usando !sub para dar el nombre de la región
- Crear el código para un lambda que retorne un listado de actores
- Comprimir el código fuente y subirlo al S3 usando AWS CLI
- Crear un template de cloudformation que construya el lambda Actores y despliegue el código cargado en en S3
- Desplegar el cloudformation template para crear el lambda con AWS CLI
